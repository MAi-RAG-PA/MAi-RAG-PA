Formula-first, always

The structural analog: Avogadro's number converts per-particle (intensive) to total count (extensive). Synthetic data has the same bridge — GMM defines per-record distribution; the cohort size converts it to data.

FORMULA:  N_A = 6.02214076 × 10²³ mol⁻¹
PLAIN ENGLISH: Avogadro's constant is the number of particles per mole — the bridge between a per-particle property (intensive) and a total property (extensive).
CONTEXT / RELEVANCE: In synthetic-data generation a GMM defines the per-record distribution (intensive: μ_k, Σ_k). To create a dataset you decide cohort size (extensive: 120K real → 480K synthetic = 4×). The scale factor — like N_A — is the bridge from model to data.
